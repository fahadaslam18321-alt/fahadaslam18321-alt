### 3️⃣ **Restaurant Management System (RMS)**

- **Key Features:**

  - Real-time Table Reservation System

  - Automated Billing with Tax & Discounts
  - Admin Dashboard with Analytics
  - Secure Authentication System
- **Architecture Highlights:**

  - Advanced DSA (BST, Stack, Hash Tables, Vectors)
  - File Handling & Data Persistence
- 🛠️ **Tech:** C++, OOP, DSA, File I/O

### 4️⃣ **SuperMarket Sales Prediction Pipeline**
An end-to-end Data Science project focusing on data preprocessing, feature engineering, and predictive analytics.
- 🔗 [Repository](https://github.com/fahadaslam18321-alt/SuperMarket-Sales-Prediction-Pipeline)
- **Pipeline Phases:**
  - Phase 1: Statistical Imputation (Mean, Median, Mode)
  - Phase 2: Structural Standardization & Text Normalization
  - Phase 3: Outlier Treatment & De-duplication
  - Phase 4: Feature Engineering & Label Encoding
- **Model Performance:** R² Score = **0.887 (88.7%)**
- 📊 **Tech:** Python, Pandas, NumPy, Scikit-Learn, Linear Regression
